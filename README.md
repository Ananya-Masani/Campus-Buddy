# Campus Buddy 🎓

Campus Buddy is a React Native app designed to help new and transfer students feel more comfortable at Rock Hill High School.

## Features

- School guide with bell schedules and key dates
- Club discovery and interest-based recommendations
- Sample student ambassador and mentor profiles
- Counselor finder and school resource links
- First-week checklist
- Mood check-in and support resources

## Built With

- React Native
- Expo
- JavaScript
- AsyncStorage

## Getting Started

1. Install Node.js.
2. Clone or download this repository.
3. Run `npm install`.
4. Run `npx expo start`.

## Demo Notice

Ambassador and mentor profiles are sample data for demonstration. Chat responses are a demo and do not represent a live messaging service. Verify school details and dates with official school sources.

## Purpose

Campus Buddy aims to make starting at a new school less confusing and help students find resources, activities, and support.
